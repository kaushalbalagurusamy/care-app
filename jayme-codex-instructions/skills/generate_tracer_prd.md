# Skill: Tracer Bullet PRD Synthesizer

## Objective
Convert Jayme's clarified product decisions into an atomic, 1-page Tracer Bullet PRD that anchors the engineering implementation.

## Guidelines
1. **Tracer Bullet Philosophy**: Implement the simplest, end-to-end slice of real functionality across all layers (Model -> View -> Router).
2. **File Location**: Save every PRD as `docs/prd/PRD_<feature_slug>.md`.
3. **Include Routing Specification**: Explicitly document the `AppRoute` enum case name, parameters, and entry/exit routes.
4. **Gherkin Acceptance Criteria**: Write 2-3 unambiguous scenarios (`Given... When... Then...`).
